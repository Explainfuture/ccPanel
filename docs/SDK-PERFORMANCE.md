# Browser SDK 性能验收

打开部署后的 `/sdk-benchmark.html`，显式点击开始，保持页面可见。页面依次运行未加载 SDK 10 秒、初始化但不采集 10 秒、每秒 20 条约 1 KiB 事件 60 秒。传输使用内存模拟 202 确认，不接入真实公司数据；因此这不是公网投递性能测试。

同步阶段仅测量调用 `track` 到返回 Promise 的耗时，持久入队阶段测量到该 Promise 完成，两者分开统计 p95/p99。记录持久/内存入队数量、拒绝、诊断、长任务、浏览器 UA、逻辑处理器数及浏览器可见设备内存。页面切换到后台使本次结果无效。

首个目标来自 PRD：Browser SDK gzip ≤ 30 KiB，约 1 KiB 事件的 track 同步阶段 p95 ≤ 2 ms。本地生产构建的 gzip 大小 5152 字节；Node SDK 5924 字节。体积和性能都应随 SDK 发布重新测量。

## 2026-10-23 首轮桌面实测

Windows 10/Win64，HeadlessChrome 155.0.0.0，浏览器报告 20 个逻辑处理器、16 GiB 设备内存；页面全程可见。由 Playwright CLI 驱动真实浏览器执行。

| 阶段 | 样本数 | 同步 p95/p99 | 持久入队完成 p95/p99 |
|---|---:|---:|---:|
| 未加载 SDK | 200 | 0 / 0.1 ms | 不适用 |
| SDK 空闲 | 200 | 0 / 0 ms | 不适用 |
| SDK 20 EPS | 1200 | 0.4 / 0.5 ms | 3.1 / 5.4 ms |

1200 次均为 queued-persistent，内存降级 0、拒绝 0、诊断错误 0，flush 后队列为 0；PerformanceObserver 支持 longtask，本次未观察到长任务。0 ms 表示低于计时分辨率，不代表绝对零开销。传输为内存确认，不能用此数据宣称网络性能。

页面只在当前设备、当前浏览器提供观测，不能由一次通过推断全部设备通过。IndexedDB 读取量的专项采样、当前/上一版浏览器矩阵、真实移动设备测试仍须补充。

## 隐私版本重新测量（2026-10-23）

m4-privacy-002 的 SDK 增加属性白名单配置与存储文本校验后，在同一 Chrome 155/Windows 条件下再次完成三组对照。使用默认配置（未启用属性白名单），20 EPS 共 1200 次均持久入队，同步 p95/p99 为 0.4/0.6 ms，入队完成 p95/p99 为 3.4/6.0 ms；无内存降级、拒绝、诊断或长任务，最终队列空。Browser gzip 5503 字节，Node gzip 6277 字节。网络仍为内存确认，不能作为公网延迟或完整浏览器矩阵证据。

## Node 文件队列生命周期（2026-10-23）

指定outboxPath时，文件队列在首次使用才打开，因此SDK构造参数校验失败不创建锁。close会等待已排队的文件写入结束，随后释放本进程取得的锁；关闭后的方法拒绝outbox_closed，不能在其他进程取得队列后继续写入。shutdown无论flush是否失败均释放SDK资源并关闭文件队列。

文件解析失败保留原始内容，仅释放自身取得的锁；不要把损坏文件当空队列覆盖。正常重启可认领已退出进程的PID锁；认领期间用独立的.lock.reclaim串行保护，防止两个重启者删除对方的新锁。认领者若在临界区被强杀，留下的.reclaim会明确阻止自动认领，需要运维先停止所有使用该outboxPath的进程、确认锁记录的PID及队列文件、保存副本，再移除遗留认领标记并启动唯一写入者。不能在仍有写入者时清锁；PID复用或无法确认进程退出时保持拒绝。文件队列适用于本地单机文件系统，不支持多个主机共享文件。

本步Node gzip为6473字节，Browser为5509字节；本地文件测试覆盖读失败不删源、竞争失败不删他人锁、关闭排空、关闭后拒绝、无效配置零文件副作用、并发死PID认领和遗留认领标记拒绝。模拟死PID只证明认领并发逻辑，不替代真实断电或文件系统损坏演练。

# Browser SDK 性能验收

打开部署后的 `/sdk-benchmark.html`，显式点击开始，保持页面可见。页面依次运行未加载 SDK 10 秒、初始化但不采集 10 秒、每秒 20 条约 1 KiB 事件 60 秒。传输使用内存模拟 202 确认，不接入真实公司数据；因此这不是公网投递性能测试。

同步阶段仅测量调用 `track` 到返回 Promise 的耗时，持久入队阶段测量到该 Promise 完成，两者分开统计 p95/p99。记录持久/内存入队数量、拒绝、诊断、长任务、浏览器 UA、逻辑处理器数及浏览器可见设备内存。页面切换到后台使本次结果无效。

首个目标来自 PRD：Browser SDK gzip ≤ 30 KiB，约 1 KiB 事件的 track 同步阶段 p95 ≤ 2 ms。本地生产构建的 gzip 大小 5152 字节；Node SDK 5924 字节。体积和性能都应随 SDK 发布重新测量。

## 2026-10-23 首轮桌面实测

Windows 10/Win64，HeadlessChrome 155.0.0.0，浏览器报告 20 个逻辑处理器、16 GiB 设备内存；页面全程可见。由 Playwright CLI 驱动真实浏览器执行。

| 阶段 | 样本数 | 同步 p95/p99 | 持久入队完成 p95/p99 |
|---|---:|---:|---:|
| 未加载 SDK | 200 | 0 / 0.1 ms | 不适用 |
| SDK 空闲 | 200 | 0 / 0 ms | 不适用 |
| SDK 20 EPS | 1200 | 0.4 / 0.5 ms | 3.1 / 5.4 ms |

1200 次均为 queued-persistent，内存降级 0、拒绝 0、诊断错误 0，flush 后队列为 0；PerformanceObserver 支持 longtask，本次未观察到长任务。0 ms 表示低于计时分辨率，不代表绝对零开销。传输为内存确认，不能用此数据宣称网络性能。

页面只在当前设备、当前浏览器提供观测，不能由一次通过推断全部设备通过。IndexedDB 读取量的专项采样、当前/上一版浏览器矩阵、真实移动设备测试仍须补充。
